# Grounded DI Education Apps

This repository combines a youth-app feature description with a dated German-language demo.

## Contents

| Artifact | Repository record |
|---|---|
| [README.md](README.md) | Labels the intended audience as ages 13+ and describes proposed safety, privacy, authorship, upload-control, offline, and transparency features. |
| [DI_German_Language_Demo.md](DI_German_Language_Demo.md) | Dated 1 August 2025. Contains three scripted tone-attribution scenarios, including teacher, friend, and panda voices, plus Hamburg and Bavarian examples. |

## Evidence boundary

The repository contains these two Markdown files, not application source or evaluation records. The feature list describes intended product behavior; it does not demonstrate enforcement of age-appropriateness, privacy, upload controls, or offline operation. The German examples are scripted demonstrations, not a measured evaluation of tone or dialect recognition.
